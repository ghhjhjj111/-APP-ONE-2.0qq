# 原生社区交友婚恋视频即时通讯双端APP源码ONE兔2.0

源码获取：ym7k.com/19840/

## 一、技术架构

客户端：Android 原生 + iOS 原生（不是 uniapp 套壳）
后端：PHP（ThinkPHP），IM 即时通讯服务，支持对接第三方音视频 SDK
交付包包含：安卓源码、苹果源码、后端源码、H5 端、数据库、后台管理系统
原生优势：消息推送延迟低、音视频通话流畅、适配手机权限，适合做长期运营的婚恋社交 APP。

## 二、核心功能模块

### 1. 用户资料 & 婚恋档案

注册登录、实名认证、头像相册；完善婚恋标签：年龄、身高、学历、收入、婚史、择偶要求、房车、籍贯；支持择偶条件筛选，标签精准匹配；个人主页、访客记录、谁看过我、好感 / 心动、拉黑屏蔽。

### 2. 附近交友、智能匹配

LBS 定位，按距离排序展示附近异性；智能推荐匹配，根据择偶条件自动推送；支持在线状态、距离、年龄、在线时间筛选。

### 3. 社区动态广场

用户发布图文、短视频动态；点赞、评论、收藏；话题分类，动态后台审核；支持关注作者，信息流浏览，打造社交氛围。

### 4. IM 即时通讯（核心）

一对一私聊，文字、图片、语音、表情；消息已读未读状态；支持实时语音通话、视频通话；消息离线推送、聊天记录保存；敏感词过滤，违规聊天内容监控。

### 5. 会员 & 付费体系（主流变现）

VIP 会员套餐：月卡 / 季卡 / 年卡，解锁查看联系方式、无限打招呼、隐身访问、优先推荐；
付费礼物：在线送礼、礼物特效；
付费置顶：个人资料置顶、动态置顶；
充值钱包，余额消费，资金流水记录。

### 6. 互动玩法

心动喜欢、互相匹配配对；打招呼、搭讪消息；相册解锁（付费查看私密相册）；相亲邀约。

### 7. 后台管理功能

- 用户管理：会员列表、实名认证审核、封禁用户、资料审核
- 内容审核：动态、相册、评论、聊天内容风控，举报处理
- IM 监控：违规聊天记录查看、敏感词库配置
- 订单财务：充值订单、会员订单、礼物收益、提现管理
- 广告配置：首页轮播、弹窗广告
- 数据统计：新增用户、活跃用户、付费营收、匹配数据图表
- 权限配置：多管理员角色、操作日志
